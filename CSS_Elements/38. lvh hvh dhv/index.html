Viewport Height Units Explained:

  • LVH (Large Viewport Height): 1lvh is 1% of the large viewport height (excludes browser UI elements when they're visible)
  • HVH (Small Viewport Height): 1hvh is 1% of the small viewport height (includes browser UI elements)
  • DVH (Dynamic Viewport Height): 1dvh is 1% of the dynamic viewport height (adjusts automatically as browser UI appears/disappears)

Try resizing your browser window or showing/hiding browser UI elements to see the differences.
